05Playlists de YouTube

Pegas una URL de playlist de YouTube.

El bot muestra el nombre y las canciones encontradas.

📁 Nombre de playlist
🎵 Canciones encontradas

Pulsa el botón para iniciar el análisis.

🔎 Analizar playlist

Después procesa cada canción, buscando la mejor coincidencia en Soulseek.

Al terminar puede pedirte el nombre final con el que quieres guardar la playlist.

06Playlists de Spotify

Pega una URL de playlist de Spotify como la del ejemplo.

https://open.spotify.com/playlist/...

El bot obtiene las canciones de Spotify y después las busca individualmente en Soulseek.

Puedes iniciar o cancelar la descarga y, al finalizar, elegir el nombre definitivo de la playlist.

07Playlists M3U / M3U8

También puedes importar una playlist M3U.

El nombre del archivo original se utiliza durante el procesamiento, pero después puedes indicar el nombre final que quieres.

La playlist generada apunta a los archivos reales de tu biblioteca.

09Calidad

Pendiente de verificar

La propuesta consiste en mostrar esta pregunta antes de iniciar una búsqueda o descarga.

🎧 ¿Qué formato prefieres?

[ 🎵 MP3 320 kbps ]
[ 💎 Mejor calidad disponible ]

La idea es que esa elección afecte a toda la operación: una canción individual, todo un álbum o todas las canciones de una playlist.

💎 Mejor calidad disponible priorizaría FLAC o formatos sin pérdida y la mejor fuente disponible.

🎵 MP3 320 kbps buscaría específicamente ese formato y calidad.

El selector se planteó como mejora. Su funcionamiento en la versión actual del bot queda pendiente de verificar en esta conversación.

10Fallos y reintentos

Si una fuente de Soulseek falla, el backend recuerda esa fuente e intenta buscar otra automáticamente.

Este ejemplo muestra el cambio de fuente.

Fuente A → falla
        ↓
Se excluye Fuente A
        ↓
Busca otra fuente
        ↓
Fuente B

Si no existe otra fuente válida, la descarga termina como fallida y Telegram te lo notifica.

Una playlist con más del 50 % de FLAC se clasifica como lossless.

Nombre.m3u

Además, si añades a una playlist gestionada una canción individual que estaba directamente en lossless/ o normal/, el sistema puede moverla físicamente a la carpeta de esa playlist y actualizar sus referencias.
